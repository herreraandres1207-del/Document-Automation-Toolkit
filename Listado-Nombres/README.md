# Listado de nombres

## Descripción

Herramienta desarrollada en PowerShell para generar automáticamente un listado de nombres de archivos PDF contenidos en una carpeta.

## Funcionalidad

- Busca archivos PDF en una carpeta.
- Extrae únicamente los nombres.
- Genera un archivo TXT con el listado.
- Facilita inventarios documentales y controles de calidad.

## Tecnologías

- PowerShell
- Windows
