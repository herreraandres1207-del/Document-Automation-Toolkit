# Validador de PDF

## Descripción

Herramienta desarrollada en PowerShell para verificar la integridad y accesibilidad de archivos PDF, identificando documentos dañados, corruptos o con errores que puedan afectar su apertura, visualización o procesamiento.

## Funcionalidad

- Analiza archivos PDF de una carpeta.
- Detecta documentos que no pueden abrirse correctamente.
- Identifica posibles errores estructurales en los archivos.
- Genera un reporte con el estado de cada PDF analizado.
- Facilita procesos de control de calidad documental.
- Reduce riesgos asociados a archivos incompletos o corruptos.

## Tecnologías

- PowerShell
- Validación de archivos PDF
- Automatización de procesos
- Windows
- QPDF
