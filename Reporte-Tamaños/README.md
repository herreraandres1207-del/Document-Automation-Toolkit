# Generador de Reporte de Tamaños

## Descripción

Herramienta desarrollada en PowerShell para obtener el tamaño de archivos de una carpeta y generar automáticamente un reporte en formato TXT con la información recopilada.

## Funcionalidad

- Analiza los archivos contenidos en una carpeta.
- Obtiene el tamaño individual de cada archivo.
- Genera un reporte TXT con los resultados.
- Facilita auditorías documentales y controles de almacenamiento.
- Permite identificar archivos de gran tamaño de forma rápida.

## Tecnologías

- PowerShell
- Gestión de archivos
- Automatización de procesos
- Windows
