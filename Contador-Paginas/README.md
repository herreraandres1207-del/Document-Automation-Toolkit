# Contador de páginas PDF

## Descripción

Herramienta desarrollada en PowerShell para analizar archivos PDF y generar automáticamente un reporte con la cantidad de páginas de cada documento.

## Funcionalidad

- Analiza archivos PDF de una carpeta.
- Obtiene el número total de páginas de cada documento.
- Genera un archivo TXT con el resultado.
- Facilita inventarios documentales y procesos de auditoría.
- Permite validar que los documentos tengan la cantidad de páginas esperada.

## Tecnologías

- PowerShell
- Procesamiento de archivos PDF
- Windows
- QPDF
