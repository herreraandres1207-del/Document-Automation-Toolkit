# Renombrador Masivo de Archivos

## Descripción

Herramienta desarrollada en PowerShell para realizar cambios de nombre masivos en archivos utilizando una lista previamente definida, permitiendo estandarizar nomenclaturas de forma rápida, segura y eficiente.

## Funcionalidad

- Lee una lista de nombres desde un archivo TXT.
- Renombra múltiples archivos de forma automática.
- Reduce errores asociados al renombrado manual.
- Facilita procesos de organización y normalización documental.
- Optimiza tareas repetitivas en grandes volúmenes de archivos.

## Tecnologías

- PowerShell
- Gestión de archivos
- Automatización de procesos
- Windows
