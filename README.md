# Document Automation Toolkit

Colección de herramientas desarrolladas en PowerShell para automatizar procesos de gestión documental, control de calidad y administración de archivos.

## Herramientas Incluidas

### 📄 Listado de Nombres
Genera automáticamente un archivo TXT con los nombres de los documentos encontrados en una carpeta.

### 📊 Reporte de Tamaños
Obtiene el tamaño de los archivos y genera un reporte en formato TXT para auditorías y controles documentales.

### 📑 Contador de Páginas PDF
Analiza archivos PDF y genera un listado con la cantidad de páginas de cada documento.

### ✏️ Renombrador Masivo
Permite renombrar múltiples archivos utilizando una lista de nombres previamente definida.

### ✅ Validador de PDF
Verifica la integridad de archivos PDF, detecta documentos dañados o ilegibles y genera informes detallados de validación.

## Tecnologías Utilizadas

- PowerShell
- QPDF
- Automatización de procesos
- Gestión documental
- Windows

## Casos de Uso

- Inventarios documentales
- Auditorías de archivos
- Control de calidad documental
- Organización masiva de documentos
- Validación de integridad de PDFs
